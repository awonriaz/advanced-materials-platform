# Hyperledger Fabric implementation

This folder contains a real JavaScript chaincode implementation for the exam's blockchain traceability requirement.

## What it demonstrates

- Material passport creation
- Immutable custody transfer history
- TensorFlow quality inspection evidence recorded on-chain
- ESG/carbon lifecycle event recording
- Certification validation logic similar to smart-contract compliance checks

## Commands

Run from WSL or EC2 Linux shell:

```bash
bash fabric/scripts/bootstrap_test_network.sh
bash fabric/scripts/deploy_material_passport.sh
bash fabric/scripts/invoke_material_demo.sh
```
